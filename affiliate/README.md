# 어필리에이트 파트너 탐색 시스템 - 목업

크리에이터(어필리에이트 파트너) 탐색 및 관리 시스템의 프론트엔드 목업.

- 실행: `affiliate/index.html` 을 브라우저에서 열기
- 라이브: https://syleelfcorp.github.io/affiliate/
- 이미지: `affiliate/img/` (c-01~50 크리에이터 사진, a-01~50 아바타 더미)

## 디자인 기준

- 톤앤무드: cosmos.so 참고, 배경 흰색, UI 크롬 절제
- ink `#141518` / point `#6919CD` (CTA 최소 범위) / primary-dark `#5614A8`
- 라인 `rgba(0,0,0,0.05)` / 라인 강조 `rgba(0,0,0,0.10)`
- 폰트 Pretendard, 스케일 13 / 14 / 16 / 17 / 19 / 22
- 거터 32px, 카드 라운드 4px, GNB 90px

## 구성

- 상단: 로고 + 알약형 검색바(검색 버튼 내장) + 내비. 필터 토글/이미지 검색 없음
- 태그 필터: 한 줄 버튼 바 `[성별] [연령] [팔로워] [# 태그]` + 초기화, 각 버튼 클릭 시 드롭다운. 모두 다중 선택
  - 태그 드롭다운은 룩 / 페르소나 / 무드 칩 그룹
- 카드 그리드: JS 마소닝(가장 짧은 열 우선), 최대 약 6열
  - 기본: 좌상단 크리에이터(아바타 + 아이디)
  - hover: 우상단 저장 버튼 + 하단 정보 패널(backdrop-blur, 태그 최대 3개 + 지표)
  - 저장 버튼 -> 폴더 선택 팝오버(다중 폴더 저장, 새 폴더 만들기)

## 변경 이력

### v0.1
- 최초 목업. 검색바(필터 토글/이미지 검색 포함), 태그 필터 6줄 전체 노출, CSS multi-column 마소닝, 웜톤 배경

### v0.2
- 태그 필터를 한 줄 드롭다운 버튼 바로 변경(성별 / 연령 / 팔로워 / 태그)
- 카드 정보 hover 노출, 이미지 미세 줌
- 웜톤 -> 쿨톤 전환, column-width 기반 그리드

### v0.3
- GNB 높이 90px, 폰트 스케일 20% 확대, 필터 버튼/칩 확대
- 초기화 버튼 상시 노출
- 검색바 알약형 + 검색 버튼 내장, 좌측 아이콘
- 배경 전부 흰색, 거터 32px

### v0.4
- CSS column -> JS 마소닝(열 밀림 버그 해결)
- 결과 카운트 / 안내 문구 제거
- 라인 컬러 옅게 조정
- 카드 hover 동작 정리: 프로필은 기본 노출, 저장 버튼 / 정보 패널은 hover
- 위시 하트 -> "저장" 버튼 + 폴더 선택 팝오버(폴더 리스트, 새 폴더 만들기)
- 하단 정보 패널 border 제거, backdrop-blur 강화
- 카드 내부 여백 16px 통일
- 실제 크리에이터 사진 50장 연결(GitHub raw), 카드 수 24 -> 50
- 카드 세로 비율 다양화(임시 테스트, 원본 비율 협의 후 수정 예정)
- 연령 / 팔로워 구간 라벨에 물결표(~) 사용

## 미확정

- 카드 세로 길이(비율) 처리 방식 - 원본 사진 비율 수급 방법 협의 필요
- 크리에이터 아바타 - 현재 더미
- 크리에이터 메타(아이디 / 팔로워 / 태그) - 현재 자동 생성 더미
