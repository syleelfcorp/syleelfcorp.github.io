# 어필리에이트 파트너 탐색 시스템 - 목업

어필리에이트 파트너 탐색 및 관리 시스템의 프론트엔드 목업.

- 실행: `affiliate/index.html` 을 브라우저에서 열기
- 라이브: https://syleelfcorp.github.io/affiliate/
- **디자인 정의서: `affiliate/DESIGN.md`** (토큰·컴포넌트·인터랙션 전체 스펙)
- 이미지: `affiliate/img/` (c-01~50 파트너 사진, a-01~50 아바타 더미)

## 화면 / 라우팅 (URL 해시)

| 해시 | 화면 |
|---|---|
| `#explore` (또는 없음) | 탐색 - 검색 + 태그 필터 + 파트너 그리드 |
| `#search/<query>` | 검색 결과 (제목=검색어, 정렬만, 필터/탭 없음) |
| `#folders` | 폴더 목록 |
| `#folder/<n>` | 폴더 상세 (n = 폴더 인덱스) |

- 파트너 상세는 오버레이 모달 (해시 라우팅 대상 아님)
- 폴더 상세의 "공유" 버튼은 `#folder/<n>` 링크를 클립보드에 복사

## 디자인 기준

- 배경 흰색, UI 크롬 절제, 이미지 중심의 갤러리 톤
- ink `#141518` / point `#6919CD` (CTA 최소 범위) / primary-dark `#5614A8`
- 라인 `rgba(0,0,0,0.05)` / 라인 강조 `rgba(0,0,0,0.10)`
- 폰트 Pretendard, 스케일 13 / 14 / 16 / 17 / 19 / 22, 페이지 타이틀 32
- 거터 32px, 카드 라운드 4px, GNB 90px
- 페이지 헤드 margin-top 40px (폴더 목록·폴더 상세 공통)

## 구성

- 상단: 로고 + 알약형 검색바(검색 버튼 내장) + 내비(폴더 / 관리자)
- 태그 필터: 한 줄 버튼 바 `[성별] [연령] [팔로워] [# 태그]` + 초기화, 각 버튼 클릭 시 드롭다운. 모두 다중 선택
- 카드 그리드: JS 마소닝(가장 짧은 열 우선)
  - 기본: 좌상단 파트너(아바타 + 아이디)
  - hover: 우상단 저장 버튼 + 하단 정보 패널(backdrop-blur, 태그 최대 3개 + 지표)
  - 저장 버튼 -> 폴더 선택 팝오버(다중 폴더 저장, 새 폴더 만들기). 저장 상태는 SAVES 스토어로 전 화면 동기화
- 파트너 상세 모달: 좌측(540px) 히어로 4:5 + 정보 + 스탯 3개 + 태그 + 소개 + 대표 콘텐츠 / 우측 유사 파트너(홈 카드 UI, 최소 2열, 공유 태그 있는 만큼만 노출)
- 폴더 목록: 타일 커버 = 좌측 큰 이미지 1개(4:5) + 우측 4:5 이미지 2개, gap 1px. 폴더명 19px, 명수 14px
- 폴더 상세: 뒤로가기 + 타이틀(32px) + `N명 · 공개/비공개` + 공유 버튼 + 더보기(...) 메뉴(공개/비공개 전환, 폴더명 변경) + 저장 파트너 마소닝

## 변경 이력

### v0.1 ~ v0.4
- v0.1: 최초 목업. CSS multi-column 마소닝, 웜톤
- v0.2: 태그 필터 한 줄 드롭다운, 카드 hover 정보, 쿨톤
- v0.3: GNB 90px, 폰트 +20%, 검색바 알약형, 배경 흰색, 거터 32
- v0.4: JS 마소닝, 저장->폴더 팝오버, 실제 사진 50장, 카드 비율 다양화, 연령/팔로워 물결표

### v0.5
- 파트너 상세 모달 추가 (오버레이, 뷰포트 고정, 좌/우 컬럼 내부 스크롤)
  - 수평 2단: 좌측 프로필+정보+대표콘텐츠 / 우측 유사 파트너(홈 카드 UI 재사용, 저장 동작 유지)
- 폴더 화면 추가: 폴더 목록 + 폴더 상세
  - 폴더 타일 커버(큰 이미지 1 + 작은 2)
  - 폴더 상세: 공유(링크 복사) + 더보기 메뉴(공개/비공개 전환, 폴더명 변경)
- 검색 결과 화면 추가 (`#search/<query>`): 제목=검색어, 정렬(관련도/팔로워/조회수)만, 필터·탭 없음
- URL 해시 라우팅 (`#explore` / `#search/...` / `#folders` / `#folder/<n>`)
- "내 파트너" -> "폴더" 로 명칭 변경
- 페이지 타이틀 32px, 페이지 헤드 margin-top 40px
- 하단 푸터 텍스트 제거, 콘텐츠 하단 padding 40px
- scrollbar-gutter: stable both-edges (좌우 여백 대칭)
- 필터 팝오버: backdrop로 본문 클릭 차단 + 최우선 z-index

## 미확정

- 파트너 아바타 / 메타(아이디·팔로워·태그) - 현재 자동 생성 더미
