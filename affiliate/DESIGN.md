# 어필리에이트 파트너 탐색·관리 시스템 — 디자인 정의서

크리에이터(어필리에이트 파트너)를 탐색·검색·저장·관리하는 웹 서비스의 프론트엔드 목업 디자인 스펙.

- 목업: `affiliate/index.html` (단일 파일, 브라우저에서 바로 열림)
- 라이브: https://syleelfcorp.github.io/affiliate/

---

## 1. 디자인 원칙

- 색은 잉크(먹색) 기준. **포인트(퍼플)는 CTA 등 최소 범위에만** 사용
- 라인·구분선은 아주 옅게. 그림자·테두리 남용 금지
- 카드/타일의 정보는 평소엔 조용하게, hover 시 드러남
- 인터랙션 요소(버튼)는 **원형 아이콘 버튼**으로 통일 (홈, 뒤로가기, 공유, 더보기, 정렬)

- **GNB**: 좌측 홈 아이콘(스트로크, 원형 테두리 없음, 클릭 시 탐색 홈) / 가운데 알약형 검색바 / 우측 내비(`폴더`, `관리자`)
- **검색바**: 높이 60px, 알약형, 좌측 검색 아이콘 + 인풋 + 우측 내장 검색 버튼(point). Enter 또는 버튼 클릭으로 검색

## 4. 컴포넌트

### 4.1 태그 필터 바 (탐색 화면 전용)

- 한 줄 버튼 바: `[성별 ▾] [연령 ▾] [팔로워 ▾] [# 태그 ▾]` + `초기화`
- 버튼 높이 44px, 알약형. 선택 시 **ink 배경 + 흰 글씨 + 카운트 뱃지**
- 클릭 시 드롭다운 팝오버 (흰 패널, radius 14, 소프트 섀도우)
  - 성별/연령/팔로워 = **리스트형** (행 hover `--row-hover`, 선택 시 좌측 체크 + `--row-sel` 배경)
  - `# 태그` = **넓은 팝오버**, 룩 / 페르소나 / 무드 **칩 그룹** (칩 토글, 다중 선택)
    - 그룹 라벨 `--fs-sm`, 그룹 간격 `margin-top: 24px`
- **팝오버 열림 시 동작**
  - 투명 backdrop(`position:fixed; inset:0; z-index:210`)이 본문을 덮어 **본문 클릭 차단** — 카드/리스트를 눌러도 팝오버만 닫히고 상세로 넘어가지 않음
  - 필터 바를 `z-index:230`으로 올려 팝오버·필터 버튼을 최우선으로. 다른 필터 버튼은 계속 클릭 가능(전환)
  - 팝오버 밖(본문, 필터 바 흰 배경 포함) 클릭 / ESC → 닫힘
- 라벨 표기: 물결표(`~`) 허용 — `30대 후반~40대 초반`, `1만~5만` 등. 지표 구분자는 CSS 점(가운뎃점 미사용)

### 4.2 크리에이터 카드 (탐색·검색·폴더 상세·유사 크리에이터 공용)

- **레이아웃**: JS 마소닝 (가장 짧은 열에 순서대로 배치). 열 폭 기본 `COL_W = 340px`, 거터 32px, 리사이즈 시 열 수 바뀌면 재배치
- 카드 = 이미지 풀블리드 + 정보 레이어. `border-radius: 4px`, 상·하단 스크림 그라데이션 상시
- **기본 노출**: 좌상단 크리에이터(아바타 + 아이디, 아이디 14px, 인스타 핸들 `.`/`_` 허용)
- **hover 노출**:
  - 우상단 **흰색 알약 "저장" 버튼** (저장되면 "저장됨" + ink 반전)
  - 하단 **글래스모피즘 정보 패널** (`backdrop-filter: blur(40px)`, border 없음): 태그 칩 최대 3개 + `팔로워 N · 조회수 N`
  - 이미지 미세 줌(scale 1.04)
- 카드 내부 여백: 상단 16 / 하단 16 (모달 내 유사 크리에이터 카드만 상단 8·좌우 12, 하단 12로 축소)
- 카드 클릭(저장 버튼 제외) → 크리에이터 상세 모달

### 4.3 저장 폴더 팝오버

- "저장" 버튼 클릭 시 카드/모달 우상단에 뜨는 팝오버
- 폴더 행: 대표 썸네일 + 폴더명 + `N명(· 비공개)` + 저장 시 원형 체크
- **다중 폴더 저장** 가능 (행 토글)
- 하단 `+ 새 폴더 만들기` (이름 입력받아 즉시 추가·저장)
- 저장 상태는 중앙 스토어(`SAVES`)로 관리 → 탐색·검색·폴더·모달 어디서 저장해도 동기화, 폴더 카운트 실시간 반영

### 4.4 크리에이터 상세 모달

- 카드 클릭 시 오버레이. 스크림(`rgba(10,11,13,0.55)` + blur), 스크림/X/ESC로 닫힘, 배경 목록 유지
- **뷰포트 안에 완전히 수납** (`max-height: calc(100vh - 80px)`), 좌/우 컬럼이 각각 내부 스크롤. 스크림 패딩 40px 빼고 꽉 참
- **수평 2단 구조**
  - **좌측 (고정 540px)**: 히어로 이미지(4:5) → 아바타·아이디·플랫폼 → `저장`(폴더 팝오버)·`원문 보기` → 스탯 3개(팔로워 / 평균 조회수 / 게시물) → 태그(읽기 전용) → 소개 → **대표 콘텐츠**(4:5 썸네일 6개 1줄)
  - **우측 (가변)**: **유사 크리에이터** — 홈과 **동일한 카드 UI + 저장 동작**. 열 폭 210px 고정 느낌 + 최소 2열(폭 채움, 우측 빈 공간 없음), 공유 태그가 있는 크리에이터만 노출(최대 표시 상한 넉넉). 제목에 개수 표기, 0명이면 빈 상태
  - 유사 카드 클릭 → 모달이 해당 크리에이터로 교체(스크롤 리셋)
- 920px 이하 세로 스택

### 4.5 폴더 타일 (폴더 목록)

- `grid-template-columns: repeat(auto-fill, minmax(320px, 1fr))`, gap 24px
- **커버**: 비율 `6/5`, 좌측 큰 이미지 1개(최신, 4:5 전체 노출) + 우측 4:5 이미지 2개 세로 스택. 썸네일 간 gap `1px`
  - grid `2fr 1fr` × `1fr 1fr`, 큰 이미지는 세로 2행 span. 각 썸네일은 `overflow:hidden` 셀로 감싸 hover 시 이미지가 `scale(1.05)` 확대돼도 gap 유지·박스 밖 안 튀어나옴
  - 멤버 3명 미만이면 이미지 순환해서 채움. 빈 폴더는 "비어 있음"
- 폴더명 `--fs-xl`(19px) + 비공개 자물쇠, 그 아래 명수 `--fs-sm`(14px)
- 마지막 타일 = `+ 새 폴더 만들기` (점선 커버)

### 4.6 폴더 상세

- **뒤로가기**: 원형 아이콘 버튼(왼쪽 화살표, 44px, 텍스트 없음) — 폴더 목록으로
- 타이틀 32px + 비공개 자물쇠, 그 아래 `N명 · 공개/비공개`
- 우측 액션 (원형 아이콘 버튼):
  - **공유**: 링크 아이콘. 클릭 시 `#folder/<n>` 링크를 클립보드 복사 + "링크가 복사되었어요" 토스트
  - **더보기(⋯)**: 클릭 시 드롭다운(필터 팝오버와 동일 스타일)
    - `공개/비공개로 전환` — 상태 즉시 반영(자물쇠·서브텍스트)
    - `폴더명 변경` — 이름 입력받아 반영
- 본문: 저장 크리에이터 마소닝 그리드. 비어 있으면 "아직 저장한 크리에이터가 없어요"

### 4.7 검색 결과 화면

- 헤더 검색바 입력 후 Enter/검색 → `#search/<검색어>`로 이동
- 좌측: **검색어를 타이틀로**(32px), 검색바에도 검색어 유지
- 우측: **원형 아이콘 정렬 버튼(↕)** → 드롭다운
  - `최신순` / `오래된순` / `인기순` (필터 팝오버와 동일 스타일, 현재 선택 체크). 기본 최신순
  - 인기순 = 팔로워순, 최신/오래된순 = 더미(인덱스 기준)
- **필터·탭 없음**
- 매칭: 크리에이터 아이디 또는 태그 부분일치. 결과 없으면 "검색 결과가 없어요"
- 결과 카드 = 홈과 동일 (클릭 시 상세 모달)

### 4.8 토스트

- 화면 하단 중앙, ink 배경 알약, `--fs-sm`, 1.8초 후 사라짐

## 6. 인터랙션 규칙 요약

- 필터 팝오버가 열리면 본문은 클릭 불가 → 아무 곳이나 클릭하면 팝오버만 닫힘
- 저장은 항상 "폴더 선택"을 거침 (그냥 저장 없음)
- 저장 상태·폴더 카운트는 전 화면 실시간 동기화
- 상세 모달은 뷰포트를 벗어나지 않고 내부 스크롤
- 원형 아이콘 버튼 = 44px, 1px 테두리(`--line-strong`), hover 시 테두리 ink
- 페이지 전환·리사이즈 시 현재 화면의 그리드를 재계산
