# 어필리에이트 운영 관리자 — 통합 매핑 (serviceplan → 깃헙 affiliate)

운영 관리자 콘솔(affiliator-admin.lfmall.co.kr) **안에** 어필리에이트 운영 기능을
녹여 넣기 위한 통합 기준 문서. 구현물: `affiliate/admin/`

---

## 0. 자료별 역할 (확정)

| 자료 | 가져오는 것 | 가져오지 않는 것 |
|---|---|---|
| **실제 운영 콘솔** (스크린샷 → 추후 HTML) | **셸**: 배경(밝은 회색), LNB(다크), 탑바, 전체 크롬 | — |
| **기존 깃헙 affiliate 목업** (`affiliate/index.html` · `DESIGN.md`) | **콘텐츠 비주얼/토큰**: 카드, 상세 모달, 칩, 팝오버, 토스트, 색·폰트·라운드 | 흰 배경·자체 GNB(헤더) |
| **serviceplan 목업** (`serviceplan/…v1.1.html`) | **기능/플로우만**: 크리에이터·캠페인·속성 관리, 권한(운영/조회) | 다크 LNB·#16181d 등 **룩앤필 전부** |

> 깃헙 목업 `DESIGN.md §9`에 "관리자 영역 미설계"로 남아 있음 → 관리자용 컨트롤은
> 깃헙 **디자인 토큰을 확장**해서 새로 정의한다(아래 공통 컴포넌트 매핑).

## 1. 깃헙 디자인 토큰 (그대로 사용)

```
--ink #141518   --point #6919CD   --point-dark #5614A8
--line rgba(0,0,0,.05)   --line-strong rgba(0,0,0,.10)
--muted rgba(20,21,24,.55)   --muted-2 rgba(20,21,24,.40)
--row-hover #F3F3F5   --row-sel #ECECEF
폰트 Pretendard · letter-spacing -.01em · line-height 1.55
fs 13 / 14 / 16 / 17 / 19 / 22, 페이지 타이틀 32
라운드 카드 4 · 패널 10 · 팝오버 14 · 알약 999 · 모달 16
토스트 ink 알약, 하단 중앙, 1.8s
```

**콘솔이 더하는 것(셸)**
```
--console-bg  #F4F5F7   (콘텐츠 영역 배경 — 흰색 아님)
--lnb-bg      다크(near-black)   LNB
패널/카드는 흰색(#fff) 위에 깃헙 스타일 유지
```
> **포인트 컬러만 콘솔 블루** 기준(사용자 확정, 2026-10-13). 폰트 사이즈·버튼/칩 형태·
> 사이즈는 깃헙 톤 유지. 현재 `--point:#2F6FED`(추정) → 정확 hex는 HTML 도착 후 확정.

## 2. serviceplan 섹션 → 구현 매핑 (개요)

| serviceplan | 코드 | 깃헙 비주얼로 어떻게 |
|---|---|---|
| 크리에이터 관리 | CRE-001~005 | 깃헙 **파트너 카드 그리드 + 상세 모달** 재사용. "저장→폴더"를 "캠페인 담기"로 치환, 상세에 속성편집·관리자메모 추가 |
| 캠페인 관리 | CAM-001~003 | 폴더 목록/상세 UI 계열을 캠페인 목록/상세로 전환(커버 썸네일 그리드) |
| **속성 관리** (이번 테스트) | ATR-001 | 좌측 속성원 내비 + 우측 카드. 칩/버튼/인풋/팝오버/토스트/모달 = 깃헙 토큰 |

## 3. 공통 컴포넌트 매핑 (관리자 컨트롤 = 깃헙 토큰 확장)

| 관리자 컨트롤 | 깃헙 대응 | 사양 |
|---|---|---|
| 기본 버튼 | `.f-btn` 계열 | 흰 배경, `--line-strong` 1px, 알약 999, hover 테두리 ink |
| 주요 버튼(CTA) | `.search button` | point 퍼플, 흰 글씨, hover `--point-dark` |
| 위험 버튼(삭제) | 신규 | 흰 배경, 빨강 글씨/테두리, hover 옅은 빨강 |
| 칩/태그 | `.chip` | 알약, 선택 시 ink 반전. 카운트 뱃지는 `--muted` |
| 인풋 | `.search input`/신규 | `--line-strong` 1px, 라운드 8, focus 테두리 ink |
| 팝오버 | `.pop` | 흰 패널, 라운드 14, soft shadow |
| 모달(확인) | `.modal-scrim`/`.modal` | 스크림 `rgba(10,11,13,.55)`+blur, 라운드 16 |
| 토스트 | `.toast` | ink 알약, 하단 중앙 |

## 4. 속성 관리(ATR-001) 상세 매핑

기능 출처 = serviceplan `renderAttr / addValue / addGroup / delValue / delGroup`.
**규칙: 추가·삭제만 제공, 수정 없음.**

| 요소 | 기능 | 비주얼(깃헙 토큰) |
|---|---|---|
| 좌측 속성원 내비 | 그룹 점프, 선택 강조 | sticky 리스트, 선택 행 ink 배경(= `.opt.is-sel` 느낌의 강조) |
| 속성원 카드 | 그룹명 + 값 개수 + [속성원 삭제] | 흰 카드(4px), 헤더 좌 그룹명/우 값개수+삭제 |
| 속성값 칩 | 값명 + 연결 크리에이터 수 + ✕삭제 | 알약 칩, 카운트 `--muted`, ✕ hover 빨강 |
| 값 추가 행 | 인풋 + [＋ 추가], 중복 시 토스트 | 인풋(라운드8) + 기본 버튼 |
| 새 속성원 카드 | 인풋 + [추가] | 연회색 카드, CTA 버튼 |
| 값 삭제 확인 | 연결 크리에이터 N명 경고 | 확인 모달(복구 불가 문구) |
| 속성원 삭제 확인 | 하위 값·매핑 전체 경고 | 확인 모달 |

속성 체계(초기값) : 룩 · 페르소나 · 무드 · 성별 · 연령 · 브랜드 · 팔로워 구간
연결 크리에이터 수는 시드 더미 크리에이터 148명 기준으로 산출.

## 5. 셸/레이아웃 규칙

- **body 폭 축소 전제**: 기존 affiliate는 full-width였으나, 콘솔은 좌측 LNB가 폭을
  차지 → 콘텐츠는 **축소된 영역** 기준으로 설계. full-width 가정 금지.
- 콘텐츠 배경 = `--console-bg`(회색), 카드/패널 = 흰색.
- 페이지 = 좌측 서브내비 + 우측 본문의 2단일 수 있으나, 좁아지면 세로 스택.
- 현재 LNB·탑바는 **임시 셸**(스크린샷 근사) → 운영 콘솔 HTML 도착 시 교체.

## 6. 결정 사항

**확정 (2026-10-13)**
- **포인트 색** — 콘솔 **블루**(`--point`만 교체, 현재 #2F6FED 추정). 나머지 톤은 깃헙.
- **LNB 그룹핑** — 신규 3개는 **별도 섹션**("크리에이터 운영")으로 분리.
- **버튼/칩 형태·사이즈·폰트** — **깃헙 톤 유지**(알약, 깃헙 fs 스케일).
- **기획 전용 표기 제거** — 실제 데이터/화면에는 기획 아티팩트 금지:
  화면코드(ATR-001 등), 스펙 문구("수정 기능은 제공하지 않습니다"), "N VALUES" 라벨 등.

**HTML 도착 후 확정**
- 포인트 블루 **정확 hex**.
- **권한(운영/조회)** — 콘솔 상단 권한 표기와 serviceplan 역할 전환의 연결 방식.
- 콘솔 공통 컴포넌트(대시보드 카드/필터바/테이블/페이지네이션/안내박스)의 정확한 치수.
